# mc-trials
Investigating the MC TRIALS

Basically AI generated problems with a bug in the codes. Yes, it's AI.

There is no real purpose for these files, they are just for fun.

No environment, nothing really needed.

They are by default read-only cases, an answer can be derived just by reading the problem and code.

Some repos contain a Git history so Git might be needed for some of them which can help narrow down solutions/problem area.

These are ideally designed to be solved without using AI help. They are for **fun**, AI takes out the fun in solving them alone.

Also since they are written by AI, fairly certain AI can solve these in less than 20 seconds as well. So ask any AI for answer key lol.

Expect AI level code, documentation and whatever problems that comes along with this combination.

Fun stuff.
